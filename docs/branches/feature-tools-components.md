## 项目名称
Tools Components 工具组件合集

## 项目简介
实用工具组件集合，包含多个Windows Forms小工具，用于日常办公效率提升

## 核心功能
- NewTextByCard文本卡片工具
- SuffixChange.Form文件后缀批量修改工具

## 技术栈
- .NET 6.0
- C#
- WinForms

## 项目结构
- components/tools/NewTextByCard(文本卡片管理)
- components/tools/SuffixChange.Form(后缀批量修改)
