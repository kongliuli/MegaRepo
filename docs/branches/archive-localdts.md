# 分支说明

- **分支名称**: archive/localdts
- **分支类型**: 归档分支
- **项目名称**: LocalDts 数据迁移工具
- **项目简介**: 基于.NET的开源数据迁移工具，支持多种数据源和目标源，采用插件架构
- **核心功能**: 多数据源支持、插件架构、并行处理、批量处理、错误处理、内存优化、日志记录、WPF界面、命令行支持
- **技术栈**: .NET 8.0, C#, WPF, EF Core
- **项目结构**: DataMigration.Contracts, DataMigration.Core, DataMigration.Wpf, DataMigration.Console, DatabaseCreator, 多个插件
- **来源仓库**: https://github.com/kongliuli/LocalDts
- **归档时间**: 2025年
- **归档原因**: 项目已完成或暂停，保留代码供参考
