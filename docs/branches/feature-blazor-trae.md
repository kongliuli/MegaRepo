# 分支说明

## 分支信息

- **分支名称**: feature/blazor-trae
- **分支类型**: 功能分支

## 项目信息

- **项目名称**: Blazor.Trae Trae集成Blazor应用
- **项目简介**: 基于Blazor的Trae集成应用，包含地图标注、天气查询、待办事项等功能模块

### 核心功能

- 地图标注 (Google Maps/Leaflet/OpenLayers)
- 天气查询
- 全局待办事项
- 多地图库集成

### 技术栈

- .NET 8.0
- C#
- Blazor
- BlazorGoogleMaps
- LeafletForBlazor
- OpenLayers

### 项目结构

- Components组件 (App/Layout/Pages)
- Models模型 (TodoItem/GlobalTodoService)
- Program主程序
