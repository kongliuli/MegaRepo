## Summary
This archive keeps the current trimmed contents of `2025CodeRepository`.
The old repository was already reduced to a small preservation set, so MegaRepo
stores only those retained files instead of importing older deleted projects.

- `project-archive/by-tech-stack/wpf/FileExplorer`: WPF / MVVM file explorer sample.
- `low-preservation/DingTalkLib`: small DingTalk webhook client library.
- `low-preservation/xfyun`: WinForms sample for SparkDesk / xfyun API calls.

## Not Restored

Older projects that were removed from `2025CodeRepository` before this archive
were not brought back into MegaRepo. The gitlink previously stored at
`tmp-repos/2025CodeRepository` pointed at an older snapshot and has been replaced
with ordinary files from the cleaned repository.
