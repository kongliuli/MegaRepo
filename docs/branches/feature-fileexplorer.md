# 分支说明

- **分支类型**: 功能分支

## 项目信息

- **项目名称**: FileExplorer 文件资源管理器
- **项目简介**: 基于WPF和MVVM模式的现代化文件资源管理器，采用Material Design设计风格

### 核心功能

- 文件浏览
- 目录导航
- 文件操作
- Material Design UI
- MVVM架构

### 技术栈

- .NET 8.0
- C#
- WPF
- Material Design Themes
- MahApps

### 项目结构

- View视图 (MainContentControl)
- ViewModel视图模型 (MainViewModel/RelayCommand)
- App主程序
