# 分支信息

## 分支名称
feature/autowebclient

## 分支类型
功能分支

## 项目名称
AutoWebClient 自动化Web客户端

## 项目简介
基于CEFSharp的自动化Web客户端，集成了阿里云、支付宝订单抓取等自动化功能

## 核心功能
- CEFSharp浏览器控件
- 阿里云自动化
- 支付宝订单抓取
- 自动购票集成

## 技术栈
- .NET
- C#
- WinForms
- CEFSharp

## 项目结构
- ALiCloud 阿里云模块
- AliPayOrderCatch 支付宝订单抓取
- AutoTicket 自动购票
- 自定义WebBrowser控件
