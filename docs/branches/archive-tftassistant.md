## Summary
This archive keeps the tracked source, docs, UI, specs, and tests for
`TFTAssistant`, a Teamfight Tactics assistant project with a .NET core,
Overwolf bridge, browser-based UI shells, SQLite-backed services, and unit
tests.

## Retained Assets

- `src/TFTAssistant.Core`: domain models, recommendation engine, services, data providers, and repositories.
- `src/TFTAssistant.Overwolf`: Overwolf bridge and message types.
- `src/TFTAssistant.App`: app entry point.
- `src/ui`: desktop, overlay, and background HTML/CSS/JS shells.
- `tests/TFTAssistant.Core.Tests`: unit and integration-style tests.
- `.trae/specs`: development specs and task notes.

## Not Retained

- `packages-microsoft-prod.deb`: local Microsoft package feed installer, not project source.
