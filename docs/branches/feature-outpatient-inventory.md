## 项目名称
OutpatientInventoryManager 门诊库存管理系统

## 项目简介
门诊库存管理系统，包含CodeFirst数据模型和MAUI跨平台客户端，用于管理门诊药品和物资库存

## 核心功能
- 库存信息管理
- 物品信息查询
- CodeFirst数据模型
- MAUI跨平台客户端(Android/iOS/Windows/MacCatalyst)

## 技术栈
- .NET
- C#
- MAUI
- EF Core Code First

## 项目结构
- CodeFirst数据层(DBInfos/ItemInfomation/ItemInfoSelect/ItemInfoMationContext)
- MAUI客户端(App/ViewModels/Platforms)
