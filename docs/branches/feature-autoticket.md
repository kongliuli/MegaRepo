# 分支信息

## 分支名称
feature/autoticket

## 分支类型
功能分支

## 项目名称
AutoTicket 自动购票系统

## 项目简介
基于WinForms的自动化购票工具，支持大麦网等平台的自动购票功能

## 核心功能
- 大麦网自动购票
- 验证码识别
- 代理支持
- HTTP请求封装
- JS签名验证

## 技术栈
- .NET 5.0
- C#
- WinForms
- NodeServices

## 项目结构
- Base 基类
- Help 工具类
  - HttpContext
  - JSHelper
  - JsonHelper
  - ProxyHelper
  - Tools
  - VerifyCodeHelper
- Http 请求
- Model 模型
- DaMai 大麦网模块
