# 分支说明

## 分支信息

- **分支名称**: feature/programcell
- **分支类型**: 功能分支

## 项目信息

- **项目名称**: ProgramCell Blazor项目管理工具
- **项目简介**: 基于Blazor和Ant Design的项目管理工具，集成GitLab和Jenkins项目展示

### 核心功能

- GitLab项目展示
- Jenkins任务管理
- 项目卡片视图
- Ant Design UI
- Docker支持

### 技术栈

- .NET 8.0
- C#
- Blazor
- AntDesign
- Docker

### 项目结构

- Pages页面 (Gitlab/JenkinsJob/Index/ReadMe)
- Data数据模型 (GitLabModel/JenkinProject/ProjectCardDataView)
- Shared共享组件 (MainLayout/NavMenu)
