# 分支说明

## 分支信息

- **分支名称**: feature/dbconnection-wpf
- **分支类型**: 功能分支

## 项目信息

- **项目名称**: DbConnection.WPF 数据库连接工具
- **项目简介**: WPF版本的数据库连接管理工具，支持多种数据库连接配置和管理

### 核心功能

- 数据库连接配置
- 连接管理
- 用户设置
- 多数据库支持

### 技术栈

- .NET 8.0
- C#
- WPF
- MVVM

### 项目结构

- Models模型 (ConnectionConfigModel)
- Utils工具 (Enums)
- Views视图 (MainControl/UserSetting)
