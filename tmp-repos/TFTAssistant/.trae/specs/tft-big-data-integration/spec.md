# TFT Assistant - 大数据集成 - Product Requirement Document

## Overview
- **Summary**: 分析和集成云顶之弈/金铲铲大数据网站的内容到 TFTAssistant 工具中，为玩家提供更全面的游戏数据和分析，包括 Meta 趋势、阵容强度、装备优先级等信息。
- **Purpose**: 利用外部大数据资源，增强 TFTAssistant 的分析能力，帮助玩家更好地理解游戏 Meta，做出更明智的游戏决策。
- **Target Users**: 云顶之弈/金铲铲玩家，特别是希望提升游戏水平的进阶玩家。

## Goals
- 分析主流云顶/金铲铲大数据网站的数据结构和 API
- 实现大数据内容的获取、处理和存储
- 将大数据分析结果集成到 TFTAssistant 的 UI 中
- 提供 Meta 趋势、阵容强度、装备优先级等分析
- 确保所有功能符合 Riot 第三方工具政策

## Non-Goals (Out of Scope)
- 不直接调用第三方胜率 API（Riot 禁止）
- 不提供实时胜率预测（Riot 禁止）
- 不爬取或窃取第三方网站数据（遵守版权）
- 不展示对手实时数据（Riot 禁止）
- 不修改游戏客户端或内存（Riot 禁止）

## Background & Context
- 云顶之弈/金铲铲有多个成熟的大数据网站，如 Metasrc、TFT Stats、OP.GG 等
- 这些网站提供丰富的数据分析，包括阵容强度、装备优先级、英雄出场率等
- TFTAssistant 已经具备基础的数据获取和分析能力，需要扩展到外部大数据
- 集成大数据可以为玩家提供更全面的游戏理解，提升工具的价值

## Functional Requirements
- **FR-1**: 大数据源分析与集成
  - 分析主流大数据网站的数据结构和 API
  - 实现数据抓取和处理机制
  - 建立数据存储和更新机制

- **FR-2**: Meta 趋势分析
  - 提供当前版本的 Meta 阵容排名
  - 显示阵容强度变化趋势
  - 分析不同段位的 Meta 差异

- **FR-3**: 阵容分析增强
  - 基于大数据的阵容强度评分
  - 阵容装备优先级建议
  - 阵容克制关系分析

- **FR-4**: 装备分析增强
  - 基于大数据的装备优先级
  - 装备组合效果分析
  - 不同阵容的装备选择建议

- **FR-5**: 英雄分析增强
  - 英雄出场率和胜率分析
  - 英雄装备推荐
  - 英雄在不同阵容中的表现

- **FR-6**: 大数据 UI 集成
  - 在覆盖层中展示大数据分析结果
  - 在桌面主窗口中提供详细的大数据分析
  - 支持数据筛选和排序

## Non-Functional Requirements
- **NFR-1**: 数据更新频率
  - 大数据更新频率不超过每日一次（避免过度请求）
  - 本地缓存机制，减少网络请求

- **NFR-2**: 性能
  - 数据加载时间 < 2 秒
  - 分析计算时间 < 1 秒
  - UI 响应流畅，无明显卡顿

- **NFR-3**: 可靠性
  - 数据源不可用时的降级策略
  - 数据一致性检查
  - 错误处理和恢复机制

- **NFR-4**: 合规性
  - 所有数据展示明确标注为历史统计
  - 遵守 Riot 第三方工具政策
  - 遵守第三方网站的使用条款

- **NFR-5**: 可扩展性
  - 支持添加新的数据源
  - 支持不同游戏模式的数据
  - 支持多语言数据

## Constraints
- **Technical**:
  - 后端使用 .NET 8.0 LTS + C# 12.0
  - 数据库使用 SQLite
  - 必须遵守第三方网站的 API 使用限制
  - 必须符合 Riot 第三方工具政策

- **Business**:
  - 免费使用层级的数据获取限制
  - 尊重第三方网站的版权和使用条款
  - 不直接展示第三方网站的原始数据

- **Dependencies**:
  - 外部大数据网站的 API 或数据导出
  - 网络连接（用于数据更新）
  - 本地存储空间（用于数据缓存）

## Assumptions
- 外部大数据网站提供公开的 API 或数据导出功能
- 数据获取频率符合第三方网站的使用政策
- 用户理解大数据分析结果仅供参考，不保证游戏胜利
- 大数据分析结果明确标注为历史统计数据

## Acceptance Criteria

### AC-1: 大数据源分析与集成
- **Given**: 外部大数据网站可访问
- **When**: 系统启动或手动触发数据更新
- **Then**: 成功获取并处理最新的大数据
- **Verification**: `programmatic`
- **Notes**: 数据获取频率符合第三方网站政策

### AC-2: Meta 趋势分析
- **Given**: 系统已获取最新大数据
- **When**: 用户查看 Meta 趋势页面
- **Then**: 显示当前版本的 Meta 阵容排名和变化趋势
- **Verification**: `human-judgment`
- **Notes**: 数据明确标注为历史统计

### AC-3: 阵容分析增强
- **Given**: 用户选择特定阵容
- **When**: 查看阵容详情
- **Then**: 显示基于大数据的强度评分、装备优先级和克制关系
- **Verification**: `human-judgment`
- **Notes**: 数据来源明确标注

### AC-4: 装备分析增强
- **Given**: 用户查看装备分析页面
- **When**: 选择特定装备或阵容
- **Then**: 显示基于大数据的装备优先级和组合效果
- **Verification**: `human-judgment`

### AC-5: 英雄分析增强
- **Given**: 用户查看英雄分析页面
- **When**: 选择特定英雄
- **Then**: 显示基于大数据的出场率、胜率和装备推荐
- **Verification**: `human-judgment`

### AC-6: 大数据 UI 集成
- **Given**: 系统已获取大数据
- **When**: 用户打开覆盖层或桌面主窗口
- **Then**: 大数据分析结果正确显示，UI 响应流畅
- **Verification**: `human-judgment`

### AC-7: 合规性检查
- **Given**: 所有大数据功能已实现
- **When**: 进行合规审查
- **Then**: 确认所有数据展示明确标注为历史统计，无实时预测功能
- **Verification**: `human-judgment`
